AQI Tracker — Automated Air Quality Dashboard
shipped
Python · SQLite · GitHub Actions · Chart.js

An end-to-end pipeline that fetches live air quality data from a public API, stores it in SQLite, and computes trend analysis — rolling averages, week-over-week change, z-score anomaly detection. Data collection and dashboard regeneration run automatically every day via GitHub Actions (cron), deployed as a static site on GitHub Pages at zero server cost. The frontend is a custom Chart.js dashboard, designed from scratch rather than templated.

Cryptid Ranch — Roblox Multiplayer Game
in progress
Luau · Roblox Studio

Co-developing a multiplayer creature-collecting and PvP game with a persistent economy, real-time raiding, and full Robux monetization, alongside a friend. Built a modular server-side system across 10+ Luau modules for player data persistence, passive income generation, and auto-scaling ranch plots via DataStoreService. India's Education-Employment Paradox — Interactive Data Explainer
in progress
Data storytelling · PLFS / MOSPI datasets

An interactive explainer correcting a widespread misreading of Indian labour statistics using public PLFS datasets from MOSPI — showing that graduate unemployment (11.2%) is 3.6× the national average due to structural job mismatch, not individual failure. Synthesizing three datasets (graduate unemployment by age, female LFPR trends, rural/urban splits) into one story, using scroll-triggered animation and a government-report aesthetic to make the pattern legible.
